# 문제모음

문제지 사진을 제목별로 모아 저장하는 GitHub Pages 앱입니다. 사진과 OCR 결과는 사용자의 브라우저에서 처리하며 서버로 업로드하지 않습니다.

문제지 사진을 인식해 문제별 원본 영역을 모으고, 중복을 검토한 다음 제목별 DOCX·PDF·TXT 파일로 저장하는 브라우저 앱입니다. 문제를 생성하거나 내용을 바꾸지 않습니다.

## 실행

Node.js 20 이상에서 다음을 실행합니다.

```powershell
npm ci --ignore-scripts
npm run prepare:assets
npm start
```

브라우저에서 http://127.0.0.1:4317 에 접속합니다. 배포용 정적 파일은 `dist/`에 있습니다. `file://`로 직접 열지 말고 HTTP 서버를 사용합니다.

## 사용

1. JPG·PNG·WEBP 사진을 추가합니다. 최대 100장, 장당 15MB입니다. 사진이 큰 경우 긴 변 3200픽셀로 조정합니다. 옆으로 누운 사진이나 뒤집힌 사진은 OCR 결과를 비교해 방향을 보정합니다. 정상 가로형 문제지는 그대로 처리합니다. 사진 옆의 ‘회전’으로 직접 돌릴 수도 있습니다.
2. 자동 배치가 맞지 않으면 1단·2단을 선택하고 인식합니다. 한글·영문을 함께 인식하며 작은 글자는 인식용 이미지에서 최대 2배로 확대합니다. 글자를 읽지 못한 사진은 재시도로 표시합니다. 이미 인식한 사진은 ‘다시 인식’ 또는 ‘전체 다시 인식’을 사용합니다. 재시도가 성공한 사진만 기존 텍스트·검토 결과를 새 결과로 바꿉니다.
3. 제목·문제 영역·인식 텍스트를 원본과 대조합니다. 드래그 또는 좌표 입력으로 영역을 수정하고 누락된 문제는 같은 사진에서 새 영역으로 추가합니다. 지문을 공유하는 연속 문항은 하나의 영역에 포함하고 나머지 겹치는 영역을 제외하면 지문을 보존할 수 있습니다.
4. 중복 후보를 나란히 보고 한 문제를 제외하거나 서로 다른 문제로 확인합니다. 제외한 문제는 다시 포함할 수 있습니다.
5. 각 문제에서 검토 완료를 누릅니다. Word·PDF·TXT 중 선택하면 제목마다 파일을 만들며 여러 제목은 ZIP으로 묶습니다.

Word·PDF 기본값은 원본 영역 이미지입니다. 수식·그림·보기는 이미지로 보존되며 글자 단위 편집은 불가능합니다. 인식 텍스트 Word는 수정 가능한 글자로 저장하지만 수식·그림을 재현하지 않습니다. PDF의 한글 제목·인식 텍스트는 폰트 호환을 위해 이미지로 들어갑니다. HWP·HWPX는 현재 지원하지 않습니다.

## 중복 판정과 인식 한계

- 동일한 원본 영역의 픽셀 해시가 같은 경우만 자동 제외합니다.
- 기준 원본이 삭제되거나 영역이 바뀌면 자동 제외된 사본 하나를 다시 포함하고 재검토를 요청합니다. 사용자가 직접 제외한 문제는 그대로 둡니다.
- 문제 번호와 공백을 제외한 텍스트를 비교해 같은 문제와 유사한 문제를 후보로 보여줍니다. 수치·수식·보기 기호를 비교 문자열에서 지우지 않습니다.
- 짧은 문항도 비어 있지 않은 텍스트가 정확히 같으면 중복 후보로 표시합니다. 후보를 실제로 제외할지는 원본을 보고 결정합니다.
- 제목이 달라도 전체 작업 안에서 중복을 비교합니다. 서로 다른 문제로 확인한 쌍은 다시 묻지 않습니다. 인식 텍스트가 바뀌면 비교를 다시 수행합니다.
- 한글 OCR·번호 구분·제목 탐지는 완벽하지 않습니다. 특히 기울어진 사진, 손글씨, 수식, 그림 중심 문항, 번호 없는 문항, 공유 지문, 복잡한 다단 편집은 원본 확인과 영역 수정이 필요합니다. 검토되지 않은 문제, 해결되지 않은 중복 후보, 인식 대기 사진이 있으면 저장을 막습니다.
- 서로 다른 촬영본이 OCR에서도 크게 다르게 읽히면 중복 후보로 나오지 않을 수 있습니다. 결과를 검토해야 중복 없이 저장할 수 있으며, 완전 자동 중복 제거를 보장하지 않습니다.
- 제목 분류는 사진마다 인식한 대표 제목을 기준으로 합니다. 한 사진에 여러 제목이 있으면 문제별 분류 제목을 수정합니다.

## 개인정보와 보관

사진, OCR, 중복 비교, 문서 생성은 브라우저에서 수행합니다. 외부 AI·OCR API를 호출하지 않습니다. 스크립트·WASM·한글 모델도 같은 사이트에서 제공합니다. 앱 서버는 정적 파일만 제공합니다. 민감한 문서를 다룰 때는 관리되는 로컬 기기에서 실행하세요.

작업은 이 브라우저의 IndexedDB에 저장합니다. 다른 기기와 동기화되지 않으며 시크릿 모드·브라우저 데이터 삭제·저장 용량 부족으로 사라질 수 있습니다. 작업 백업 JSON은 사진 100장·문제 5,000개·파일 크기 500MB까지 가져올 수 있습니다. 백업에는 원본 이미지와 인식 내용이 모두 들어 있으므로 안전하게 보관하세요. 새 작업은 현재 작업을 지웁니다.

## 확인

```powershell
npm test
npm audit --omit=dev
```

자동 테스트 20개는 문제 번호·선택지 구분, 수치와 수식 보존, 제목별 묶기, 짧은 문항 비교, 자동 제외 사본 복구, 인식 중단·재시도 시 작업 격리, OCR 실패 판정·확대 좌표 복원, PDF 문제·파일명 동시 배치를 확인합니다. 브라우저 확인 기록은 `VERIFICATION.md`를 참조하세요.

OCR API와 로컬 모델 경로는 [Tesseract.js 공식 문서](https://github.com/naptha/tesseract.js/blob/master/docs/api.md)를 따릅니다. 한글 모델은 [tessdata_best](https://github.com/tesseract-ocr/tessdata_best), 영문 모델은 Project Naptha의 fast 모델입니다. 문서 생성은 docx, jsPDF, fflate를 사용하며 라이선스는 `dist/vendor/THIRD-PARTY-NOTICES.txt`에 정리합니다.
